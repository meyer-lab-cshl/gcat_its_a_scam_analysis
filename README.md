# gcat, its_a_scam: modular tools for single cell data processing and per-cell quality control

Analysis and plotting scripts to accompany the 'gcat, its_a_scam: modular tools
for single cell data processing and per-cell quality control' manuscript.

The following directories contain the scripts related to:

1. joint_annotation: Joint clustering and annotation
of the 10x Multiome PBMC dataset.  
2. 10x_atac_concordance: Concordance analysis of its_a_scam and
CellRanger pipeline for 10x scATAC-seq data.
3. parse_concordance: Concordance analysis of its_a_scam and
split-pipe for Parse Biosciences scRNA-seq data
4. benchmarking: Plotting the gcat GenomicStepVector and its_a_scam
benchmarking results.
